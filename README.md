# Telegram Chat Parser Bot
Данное программное обеспечение предназначено для извлечения списка участников телеграм-чатов на основе истории переписки. Проект разработан в рамках хакатона совместно с BotCreators.


## 📌 Описание проекта
Бот позволяет получить список участников чата, используя файлы экспорта истории сообщений. 
Это решение для аналитиков и маркетологов, позволяющее собирать данные об активной аудитории сообществ без нарушения приватности, 
так как данные не сохраняются на сервере.


## 🎯 Целевая аудитория
- **Администраторы сообществ:** для управления и анализа аудитории.
- **Маркетологи:** для сегментации пользователей и изучения конкурентных чатов.
- **Исследователи данных:** для анализа социальной активности.
- **Обычные пользователи:** которым необходимо видеть состав участников чата без прав администратора.


## ✨ Ключевые функции
1. **Загрузка данных:** Прием файлов истории чата (экспорт из Telegram Desktop). Поддержка до 10 файлов одновременно, где каждый файл не должен превышать 50 Мб.
2. **Умный парсинг:**
   - Извлечение авторов сообщений.
   - Извлечение пользователей из упоминаний (mentions).
   - Автоматическая очистка от дубликатов.
3. **Гибкая выдача результатов:**
   - ***< 50 участников:*** Список отправляется текстовым сообщением прямо в чат.
   - ***≥ 50 участников:*** Формируется и отправляется структурированный Excel-файл.
4. **Приватность:** Бот работает в режиме "обработка "на лету" — личные данные и файлы истории не сохраняются на сервере.

## 🚀 Как запустить
1. Клонируйте репозиторий:
```bash
git clone https://github.com/euchekavelo/telegram-chat-parsing-service.git 
```

2. Перейдите в папку проекта и в файле ***app.env*** установите значение токена для переменной **TELEGRAM_BOT_TOKEN**.

3. Находясь в папке проекта, запустите Docker-контейнер приложения:
```bash
docker-compose up -d
```

4. Начните взаимодействовать с ботом, токен которого используется в приложении.


## 📋 Инструкция для пользователя 
1. Откройте Telegram Desktop и перейдите в нужный чат.
2. Нажмите ***Настройки*** -> ***Экспорт истории чата***.
3. Выберите формат файла JSON для экспорта и скачайте файлы.
4. Отправьте полученные файлы боту (не более 10 штук за раз, где каждый файл не более 50 Мб). 
5. Получите готовый список участников в виде списка или Excel-файла.
